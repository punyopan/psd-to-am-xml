PSD → Alight Motion XML

Runs entirely on your device. Nothing is uploaded.

What converts
  • Text layers → editable Alight Motion text (position, size, color)
  • Image layers → magenta placeholder rectangles at the same position and size; each layer's image is in the .zip so you can import it and swap it in
  • Not yet: blend modes, layer effects, masks, fonts (defaults to Roboto)

Import the XML in Alight Motion, then replace the placeholders with the PNGs.
