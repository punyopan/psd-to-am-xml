PSD → Alight Motion XML

Runs entirely on your device. Nothing is uploaded.

What converts
  • Text layers → editable Alight Motion text (position, size, color)
  • Image layers → Alight Motion image layers at the same position, size and opacity
  • Transparent edges cropped off each layer (smaller PNGs, tighter layer boxes)
  • Hidden and empty layers are skipped
  • Not yet: clipping masks, blend modes, layer effects, fonts (defaults to Roboto)

Save the .zip to Download and extract it there (keep the folder name the same as the zip). Then import the XML from that folder in Alight Motion.
