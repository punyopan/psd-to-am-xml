Where you'll extract the images (Alight Motion looks here)
What converts
  • Text layers → editable Alight Motion text (position, size, color)
  • Image layers → Alight Motion image layers at the same position, size and opacity
  • Transparent edges cropped off each layer (smaller PNGs, tighter layer boxes)
  • Hidden and empty layers are skipped
  • Clipping masks and blend modes (Multiply, Screen, Overlay, Darken, Lighten, Subtract, Color Dodge/Burn, Hard/Soft Light, Difference, Exclusion)
  • Not supported: modes Alight Motion lacks (e.g. Linear Dodge/Add) fall back to Normal; layer effects; fonts (defaults to Roboto)

Keyflow: choose "Keyflow" above and open the downloaded .kf with Keyflow's import. Layers keep their position, opacity, blend mode and hidden state; transparent edges are cropped.

Alight Motion: Extract the .zip in your Download folder (keep the folder name the same as the zip), then import the XML from that folder. Importing the zip without extracting does not load the images.
